# Student C Studio

**Write → Run → Learn**

এটি Student C Studio-এর প্রথম Flutter ভিত্তি।

## এই সংস্করণে আছে
- C code editor
- Run button
- Output/Error panel
- বাংলা error explanation panel
- New program
- Sample program

## এখনো নেই
- প্রকৃত offline C compiler
- Save/Open file
- scanf input console
- syntax highlighting

## চালানোর নিয়ম
1. Flutter project তৈরি করুন: `flutter create student_c_studio`
2. এই ফোল্ডারের `pubspec.yaml`, `analysis_options.yaml` ও `lib/main.dart` দিয়ে তৈরি project-এর ফাইলগুলো replace করুন।
3. Terminal-এ চালান:
   - `flutter pub get`
   - `flutter run`
